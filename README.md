# Knowledge Work Workshop: Practice Materials

Practice files for the two-day Knowledge Work workshop. Use them if you don't have a work task or sample you're allowed to bring.

Everything here is **fictional**. Quillmoor Supply is an invented company: it distributes commercial kitchen equipment and parts and runs a service desk. Its people, customers, suppliers and figures are made up. You can upload or paste any of these files into any AI tool.

## What's here

| Folder | Use it for | Workshop pages |
|:---|:---|:---|
| [`day-1-mock-tasks/`](day-1-mock-tasks/) | A recurring task to carry through Day 1, if you have no task of your own: baseline, Define, Delegate, Verify, Iterate | Day 1 pages 03 to 14, Day 2 page 03 |
| [`day-2-meetings/`](day-2-meetings/) | Past meeting notes for the meeting brief, and a transcript for the follow-up draft | Day 2 pages 05 and 06 |

## How to use a file

1. **Download it.** Open the file on GitHub and use the download button, or download the whole repository with **Code → Download ZIP**.
2. **Attach it to your AI tool.** Upload the file, or paste its text into the chat.
3. **Handle CSV files with care.** Some tools read CSV files better than others. If yours struggles, open the file in a spreadsheet and paste the table in.

Treat these files the way you would treat real work: check what the tool tells you against the file itself.
