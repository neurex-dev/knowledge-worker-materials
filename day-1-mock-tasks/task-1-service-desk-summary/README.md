# Task 1: Service Desk Weekly Summary

## The request

> Every Monday morning I need a one-page summary of last week at the service desk, before the 9:30 leadership call. Tell me how many tickets came in and how many we closed, what is still open, and where we missed our response times. Flag anything I should escalate or call a customer about. Use the same layout as last week's summary so I can compare.
>
> Mara Ellison, Operations Manager

| | |
|:---|:---|
| **How often** | Weekly, every Monday |
| **Time by hand** | About 60 minutes |
| **Who reads it** | Mara, then the Monday leadership call |

## Files

| File | What it is |
|:---|:---|
| `service-desk-tickets-2026-10-19-to-25.csv` | Ticket export from the service desk system for Monday 19 to Sunday 25 October 2026. The export ran at the end of Sunday 25 October |
| `weekly-summary-2026-10-12-to-18.md` | Last week's summary, for the layout |

## Background

- **Priorities and response times:** P1 is equipment down, to be resolved the same business day. P2 is degraded, within 2 business days. P3 is routine, within 5 business days.
- **`sla_due`:** the date each ticket had to be resolved by.
- **Engineers:** Theo Banerjee leads the service desk. Ana Ruiz and Jules Martin are field engineers.

Fictional sample for workshop use. Quillmoor Supply, its people, customers, suppliers and figures are invented.
