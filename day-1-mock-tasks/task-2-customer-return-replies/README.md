# Task 2: Customer Return Replies

## The request

> Every day the shared inbox gets customers asking to return parts. I need a draft reply to each one, based on our returns policy, for me to check and send. Be clear about what we can and can't do, tell them the next step, and keep it friendly. Some of these are good customers we want to keep.
>
> Theo Banerjee, Service Desk Lead

| | |
|:---|:---|
| **How often** | Daily |
| **Time by hand** | About 10 minutes per email, 45 to 60 minutes a day |
| **Who reads it** | Theo checks each draft, then sends it to the customer |

## Files

| File | What it is |

| `customer-emails-2026-10-27.md` | Five customer emails received on Tuesday 27 October 2026 |

## Background

- **Sending:** replies go out from the service desk shared inbox, signed by the person who sends them.
- **Today's date:** treat it as Tuesday 27 October 2026 when you work out how long ago something was bought.
